# Praveen Reddy - Data Analyst Portfolio

Modern developer and data analyst portfolio built with React 19, Vite, Tailwind CSS 4, and Framer Motion.

Built during the placement training program at [TAP Academy](https://thetapacademy.com/) (full-stack development, AI and augmented reality training).

## Features

- **Fluid Splash Cursor**: High-performance interactive cursor dynamics.
- **Water-Fill Preloader**: Smooth Framer Motion entrance animation.
- **Hero Video & Reel**: Interactive character showcase with responsive controls.
- **Interactive 3D ID Badge**: Spring lanyard entrance with 3D flip visiting card and QR code.
- **Categorized Technical Stack**: Interactive glassmorphic skill cards.
- **Methodology & Process**: Scroll-driven SVG animated path tracking.
- **Project Showcase**: Flagship project highlights with live demo and repository links.
- **Experience & Leadership**: Timeline of practical internships and community contributions.
- **Interactive Contact Form**: EmailJS integration with automated fallback.

## Tech Stack

- React 19
- Vite
- Tailwind CSS 4
- Framer Motion
- AOS (Animate On Scroll)
- @emailjs/browser
- react-qr-code

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Run linter
npm run lint

# Build for production
npm run build
```
