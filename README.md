# Siddavatam Praveen Kumar Reddy — Portfolio

A modern, responsive developer and data analyst portfolio showcasing exploratory data analysis, interactive dashboards, and machine learning models.

**Live site:** https://myportfolio-mu-livid-84.vercel.app

Built during the placement training program at [TAP Academy](https://thetapacademy.com/) (full-stack development, AI and augmented reality training).

## Tech Stack

- React 19
- Vite
- Tailwind CSS 4
- Framer Motion
- AOS
- EmailJS
- WebGL

## Run Locally

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Environment Variables

To enable contact form submissions via EmailJS, create a `.env.local` file in the project root with the following variables:

```env
VITE_EMAILJS_SERVICE_ID=
VITE_EMAILJS_TEMPLATE_ID=
VITE_EMAILJS_PUBLIC_KEY=
```
